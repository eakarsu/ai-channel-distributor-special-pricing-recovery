# Channel Distributor Special-Pricing Recovery

Validate channel special pricing and recover eligible credits while preventing duplicate or unauthorized claims.

**Primary buyer:** Manufacturers and channel distributors. **Evidence:** special-price authorizations, end customers, products, distributor sales, ship-and-debit claims, eligibility, contract prices, credits, and deductions.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Program authorization library
- End-customer registry
- Product eligibility mapping
- Distributor sales ingestion
- Contract price calculation
- Resale price validation
- Claim quantity validation
- Duplicate claim detection
- Authorization period control
- Ship-and-debit calculation
- Manufacturer claim file
- Rejection remediation
- Credit memo matching
- Distributor settlement
- Program customer analytics

Run `./start.sh`, then open <http://127.0.0.1:4703>. API: `5703`.
